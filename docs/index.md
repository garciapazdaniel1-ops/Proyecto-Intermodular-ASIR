# VitalFit

## Proyecto Intermodular de 2.º ASIR

**VitalFit: Infraestructura informática del Gimnasio Paso a Paso**

Proyecto realizado para diseñar y configurar la infraestructura informática de un gimnasio situado en Talavera de la Reina.

En el proyecto se trabajarán:

- Sistemas operativos.
- Bases de datos.
- Aplicaciones web.
- Servicios de red.
- Seguridad y alta disponibilidad.
